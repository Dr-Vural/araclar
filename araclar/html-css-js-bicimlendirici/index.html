JavaScript küçültme neden yok

Gerçek bir JavaScript küçültücü kodu ayrıştırmak zorundadır; düzenli ifadeyle yapılan küçültme değişken adlarını, şablon dizgilerini ve regex değişmezlerini sessizce bozar — hata vermez, sadece yanlış çalışır.
