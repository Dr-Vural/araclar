JavaScript küçültme neden yok

Gerçek bir JavaScript küçültücü kodu ayrıştırmak zorundadır; düzenli ifadeyle yapılan küçültme değişken adlarını, şablon dizgilerini ve regex değişmezlerini sessizce bozar — hata vermez, sadece yanlış çalışır. Bu yüzden burada JS için yalnızca yorum ve fazla boşluk temizliği yapılır. Üretim için Terser ya da esbuild kullanın.

CSS ve HTML küçültme güvenlidir; pre, textarea ve koşullu yorumlar korunur.
